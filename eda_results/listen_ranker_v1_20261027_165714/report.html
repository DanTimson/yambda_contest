Controlled experiment

All CatBoost models use exactly the same expanded candidate pool and QuerySoftMax objective. base_features uses the original scalar like features; listen_features additionally uses listen history, feedback state, source ranks and sample listener trends. listen_no_sample_trends removes only the sample trend features. Future likes define all labels; short plays, dislikes and unlikes never override a positive.
